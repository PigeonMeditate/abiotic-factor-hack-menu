## 🧩 About

**Abiotic Factor Companion** is a curated list of Abiotic Factor open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, waypoint notes
- **Quality-of-Life Helpers** — inventory organizer, crafting notes, map overlay
- **Research Notes** — sector layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Resource Tracker — note nearby materials and loot spots
- Waypoint Notes — mark and review points of interest
- Map Overlay — sector map with layout annotations
- Day Counter — track in-game time for planning

### Wallhack
- Inventory Organizer — sort and label item stacks
- Crafting Notes — recipe reference and material lists
- Storage Labels — tag containers for quick lookup

### Aimbot
- Session Notes — coordinate with teammates in study runs
- Layout Markers — place notes for base building plans
- Config Profiles — save and switch helper settings
